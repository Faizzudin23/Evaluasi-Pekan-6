# Aplikasi Kasir Sederhana Kedai Senja

Aplikasi kasir berbasis JavaScript murni (Vanilla JavaScript) yang dirancang secara manual dari nol untuk mengelola manajemen stok menu, perhitungan transaksi, diskon bertingkat, promo hari, validasi pesanan, hingga pelaporan keuangan komprehensif tanpa bergantung pada library modern eksternal.

## Teknologi yang Digunakan
- **HTML5 & CSS3**: Struktur antarmuka dan penataan gaya halaman.
- **JavaScript (ES6+)**: Logika pemrograman inti, manipulasi objek, array, perulangan, dan pemrosesan data kasir.
- **Git & GitHub**: Version control system dan manajemen kolaborasi kode.

## Cara Menjalankan Proyek
1. Clone atau unduh repositori ini ke komputer lokal Anda.
2. Buka folder proyek melalui terminal atau text editor (seperti VS Code / Neovim).
3. Jalankan halaman HTML utama (atau file demo skrip JavaScript terkait) langsung melalui browser atau gunakan extension live server.
